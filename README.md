# Project_13

# Содержание проекта

 AnonymCookableClass - класс Main содержит применение интерфейса Cookable с
      преобразованием его метода, и кастомного класса Food путём вывода строчки на консоль  
 Calculator - в классе Main реализуются методы кастомного класса Calculator, 
      выполняющие простейшие арифметич-е операции  
 GenericClassWithThreePar - класс Main содержит применение обобщений(Generics)
      в параметрах класса GenericWithThree вместе с кастомными классами Animal и Realiser  
 GenericMatrix - класс Main демонстрирует применение обобщений на примере с   
      массивами, составляющими кастовый класс GenericClass.  
 LocalInnerClass - в пакете, в кастовом классе Uses отображается внутренний 
      класс Query, заданный в методе createQuery() User, задающем переменные класса. Он отображает данные объекта выводом их на консоль.  
 MinMaxArr - в классе Main реализуются методы кастомного класса MinMax, 
      выполняющие поиск минимального и максимального значений в заданном массиве. Для этого используется метод compareTo().  
 RegularClass - класс Main использует кастомный класс User, в котором имеется 
      внутренний класс Query. User содержит поля login и password, заполняемые 
      в методе printToLog() класса Query, и выводимые на консоль в том же методе.
      Т.е. Main создаёт объекты данного класса, User.  
 StaticNestedClass - здесь в двух файлах Main, разных классах, реализуются 
      вложенные классы, один - внутренний, Printable, а другой - вложенный, static Query. И функции в Query в данном пакете - такие же, как и в 
      RegularClass.
